# 成员联系方式查找参考

## 问题场景
用户要求查找公司成员（如王志文、李松）的手机号等联系方式。

## Confluence 限制
- `mcp_local_confluence_search_users` 接口返回的 user profile **不包含**手机号
- Confluence 系统设计上不存储个人联系方式

## 成功查找路径

### 路径一：应急联系人文档（已验证有效）
在 **OMC 空间** 或 **operationalSafety 空间** 中，存在定期更新的紧急联系人文档：

| 文档模式 | 示例标题 | 示例 pageId |
|---------|---------|:----------:|
| `运行安全{年份}春节假期产品紧急联系人` | 运行安全2026年春节假期产品紧急联系人 | 42893468 |
| `运行安全{年份}国庆中秋假期产品紧急联系人` | 运行安全2025年国庆中秋假期产品紧急联系人 | 31857147 |

**搜索关键词**：
- `运行安全*假期*产品紧急联系人`
- `产品紧急联系人`
- `*春节*紧急联系人`

**文档结构**：
这些文档以表格形式列出各产品线（OSM、DRCC、DBRA、通知中心等）成员的手机号。

### 路径二：项目/案例文档中提及
在切换案例、故障记录文档中，通常在文末标注"支持人员"姓名（但不含手机号）。
例如温州中医院案例中标注：支持人员：朱珂峰、王春晓、姜宜民、王志文

### 路径三：企业微信
Confluence 无法提供手机号时，建议用户：
- 企业微信搜索联系人
- 公司 OA/HR 系统查询通讯录

## 注意事项
- `search_users` 可能返回空结果（如王志文 wangzhiwen），但文档中仍可找到该人员的案例记录。此时不要放弃，继续搜索文档内容。
- 紧急联系人文档涵盖的产品线包括：**OSM、DRCC、NgFileSync、DBRA、通知中心、统一身份、lsagent**。不同产品线的紧急联系人可能不同。
