### 功能实现版本查询方法
当用户问"某个功能是哪个版本实现的"：

1. **年度迭代计划** — 查 `2024迭代` (pageId=36668707) 或 `2023-迭代` (pageId=34576569)
   - 按月份列出 DRCC 功能计划
   - 交叉对照发布版本表找到对应版本
2. **DRCC - 版本记录** (pageId=28869350) — 有按版本组织的详细功能列表（截至 V2.20.0）
3. **特定 Fusion 版本页** — 进入对应月份的页面，查看 story 级别的功能清单
4. **发版频率对照**：~月均一个大版本，可用时间反推版本号

#### 多租户实现版本示例
- 产品基调说明: 2024-04-03（Q3改造, Q4发布）
- 2024迭代: 7月~12月持续开发（平台架构任务）
- 对应版本: 推测 **V3.6.0**(2024-10) 或 **V3.7.0**(2024-12)
- 发布版本管理表确认含"多租户"文字，但具体行不可提取

### HANA 桌面演练的特殊约束
- 必须使用 **LVM 管理**的存储，不能是根文件系统
- 需要 **root 用户 + <sid>adm 实例用户**
- 快照卷大小不能低于 **100G**
- 监控阈值建议 **70%**，超过则自动关库
- 涉及目录：`/hana/shared`、`/hana/data`、`/hana/log`、`/usr/sap`
- 级联架构 (A→B→C) 中 B 演练后会导致 C 复制状态异常

## 六、华为云接入

- 华为云 **ECS 未作为独立虚拟机资产类型** 接入 DRCC
- 当前接入方式：通过 **应用资产类型**（API 脚本）间接管理
- 首次实施项目：辽宁医保（2024-07），使用 DRCC 3.18.0
- 如果需将华为云 ECS 作为独立资产纳管，需要产品侧新增第三方平台对接
