〇、模板配置速查

节点类型（画布 9 种）

类型含义用途
start开始每个流程唯一入口，承载起始表单（startSchema）
task任务单人/角色处理，可绑表单 Schema、SLA、处理人
decision决策分支判断，按表单字段条件路由（eq / ne / contains）
parallel_split并行分叉拆成多路并行
parallel_join并行汇合多路汇合后流程收敛
acceptance验收结果验收（通过 / 不通过）
closure闭环确认流程闭环确认
timer定时定时触发 / 等待
end结束流程终点

节点配置字段（属性面板）

字段说明
处理人 handler指定用户或按角色/技能匹配（如"开发人员-前端"）
SLA节点时限（默认 24h），超时自动标记预警
表单 Schemainput / textarea / select / multiselect / radio / date / number / upload / file
Expert 绑定节点挂载已发布的 Expert Deployment（AI 自动处理）
决策分支{ 目标节点: { field, op: eq/ne/contains, value } } + 默认分支
输出 output本节点产出说明（写入任务上下文，供下游继承）

发布前置校验（6 项）：开始/结束节点存在 · 无孤立节点 · 决策分支条件完整 · 任务节点处理人已绑定 · Expert 节点已绑定已发布 Deployment。

演示组合建议

⏱️ 15 分钟精华

模板 1（首演）+ 模板 3（重头戏）。先让客户理解"流程 + AI 专家"基本盘，再用缺陷流程亮出 SLA、AI 诊断、外部智能体接力三板斧。

⏱️ 45 分钟完整

模板 1 → 2 → 3 → 4。建模（1）→ 审批与 AI 预审（2）→ 智能运维（3）→ 业务普适（4），从"技术场景"讲到"人人可用"。

🏛️ 客户是管理层

模板 2 + 模板 3。多级审批 + AI 把关 + 审计，讲"管得住、可追溯"。

💻 客户是 IT / 技术

模板 3 + 模板 1。外部智能体接力 + 画布建模，讲"开放、可集成"。

录入步骤（画布操作）

  1. 「流程模板」→ 新建模板（选择类型）→ 打开发布前校验清单。
  2. 画布拖入节点 → 连线（开始 → … → 结束）。
  3. 每个 task / decision / acceptance / closure 节点：配置处理人（用户或角色/技能）、SLA、表单 Schema、输出说明。
  4. 需求分析 / 法务预审 / AI 诊断节点：在 Expert 中心确认对应 Expert 已发布，节点属性面板绑定其 Deployment。
  5. 决策节点：配置分支条件与默认分支。
  6. 点击"发布校验"，按提示补齐（处理人未绑定 / Expert 未绑定 / 分支不完整等），发布。
  7. 「项目列表」→ 绑定该模板 → 新建工作项 → 按 startSchema 填写 → 发起流程。
