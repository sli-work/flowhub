Expert Run · 重新执行 + 补充上下文 —— 交互原型

位置：任务处理页 →「Expert Run 结果」卡片。交互点：
  1. 每条 Run 头部新增 「重新执行」按钮（成功态为描边次按钮；失败态升级为紫色主按钮）；
  2. 点击后在 该 Run 卡片内部展开「补充执行上下文」输入框 —— 旧输出保持可见，可边看边写纠偏要求；
  3. 输入框支持快捷标签一键插入、字数统计（上限 2000）、⌘/Ctrl+Enter 提交、Esc 取消；
  4. 确认后新 Run 置顶进入 running 态（骨架屏 + 3s 轮询），完成后替换展示，带上下文的 Run 显示 「上下文 N 字」标记便于追溯；
  5. 重新执行期间所有「重新执行」按钮禁用，避免并发 Run。
